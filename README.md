# Portfolio Landing Page

A personal portfolio landing page designed in Figma and built with semantic HTML and CSS. Features a dark theme with responsive layouts across mobile, tablet, and desktop breakpoints.

## Features

- **Figma-to-code** workflow — designed in Figma, hand-coded from scratch
- **Semantic HTML5** with ARIA labels for accessibility
- **Responsive design** with CSS Grid and Flexbox
- **Dark theme** with green accent color palette
- **Hero section** with profile card and call-to-action
- **Project gallery** footer showcasing featured work

## Tech Stack

- HTML5 (semantic elements, ARIA attributes)
- CSS3 (Grid, Flexbox, custom properties, media queries)
- Google Fonts (Inter, IBM Plex Mono)

## Run Locally

```bash
git clone https://github.com/Pr1nc3B33/FIGma_Project.git
cd FIGma_Project
open figLanding.html
```
